
# github-cicd-node.js

![CI Pipeline Badge](https://github.com/fabrice-git-hub/github-cicd-node.js/actions/workflows/ci-cd.yml/badge.svg)

## Description

Ce projet est un exemple de configuration CI/CD pour une application Node.js.  
Il inclut un workflow GitHub Actions pour tester et déployer automatiquement le code.

## Prérequis

- Node.js >= 18
- npm
- Git

## Installation

```bash
git clone https://github.com/fabrice-git-hub/github-cicd-node.js.git
cd github-cicd-node.js
npm install
